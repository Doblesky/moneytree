# src/engine

Moteur de simulation en TypeScript pur, sans aucune dépendance à l'interface (ni React, ni DOM).
Il prend un état et des décisions, et renvoie l'état du mois suivant. Le Monte Carlo
tourne dans un Web Worker. Sous-modèles prévus : salaire, impots, enveloppes, marches,
immobilier, evenements. Arrive en phase 1.
