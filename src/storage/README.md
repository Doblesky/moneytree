# src/storage

Stockage local (IndexedDB via Dexie) : profil, progression, sauvegardes de parties, remarques.
Export et import JSON de toutes les données depuis l'écran Réglages.

Les remarques partent seulement sur geste de l'utilisateur : le bouton d'envoi ouvre le menu de
partage du téléphone, et un fichier `moneytree-remarques-AAAA-MM-JJ.txt` enregistré sur Google
Drive peut ensuite être lu par Claude.
